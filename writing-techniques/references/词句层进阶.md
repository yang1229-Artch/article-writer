# 词句层进阶：动词、通感、陌生化、具体化

从"组词意象"（两个反差词碰撞）推导出来的整族词句技巧。冬小瓜只教了组合，这族技巧教选词的底层。

## 1. 动词升级（句子的脊椎）

动词是句子里最有画面感的词。把"有/是/觉得/感到"这类弱动词，换成**有动作、有质感、能看见**的动词。

- 弱："他很生气" → 强："他摔了保温杯，水溅了一地"
- 弱："我很难过" → 强："我掐灭了烟"（冬小瓜实录）
- 练习法：每句找到核心动词，问一句"还有没有更具体的？"直到换不动为止。

## 2. 通感（感官跨界）

把一种感官的体验，写成另一种感官的体验。让"抽象的情绪"变成"能触摸/能尝到/能听见的东西"。

- "笑声很脆"（听觉 → 触觉：脆）
- "沉默压着整个屋子"（听觉 → 触觉：重量）
- "时间在墙上走得黏糊"（时间 → 触觉）
- "她的声音很凉"（听觉 → 触觉）
- 原理：情绪无法直接写，但"脆/重/黏/凉"可以被身体感受到——这其实是客观对应物在感官层的最小单位。

## 3. 陌生化（第一次看见的眼光）

用"第一次见到这个东西"的眼光去描写常见事物，去掉熟视无睹。

- Zayne 实录："关系像一面镜子，但不是平整清晰的镜子，更像一块带着纹理的水面"
- 冬小瓜实录："像几枚生了锈的铁钉"（心灰意冷）
- 方法：先写下这个东西的"功能描述"（它是什么），然后问"它长得像什么、状态像什么"，找那个反常识的相似物。

## 4. 具体化（名词要落地）

抽象名词换具体名词：时间（夜晚→凌晨的路灯下）、身体部位（手→端着水杯的手指）、物件（叶子→一片枯叶）、材质（沉默→生了锈的铁钉）。

- 一个准确的细节（"凌晨的路灯下，身无分文的我戴着耳机发呆"）胜过三个形容词（"孤独、绝望、迷茫的夜晚"）。
- 具体的东西自带情绪：锈=被腐蚀，枯叶=被揉碎，路灯=无人陪伴。

## 5. 数字与材质（精确即力量）

- 一个准确数字/材质/动作细节 > 一串形容词。
- "模考成绩下来，人家照样比我高一百多分"（Byron 实录）——数字比"差距很大"有力一百倍。

## 检查

- [ ] 弱动词（有/是/觉得/感到/非常）还剩几个？
- [ ] 有没有一处感官跨界（通感）？
- [ ] 有没有"第一次看见"的陌生化描写？
- [ ] 抽象名词是否换成了具体物（路灯/枯叶/手指/铁钉）？
