# 文笔底层逻辑（一切技巧的根）

## 一条根原理

**不替读者完成，只给原材料。**

- 直写情绪（"我很烦""我心灰意冷"）= 我替读者把答案说了，读者无事可做，文字就白。
- 动作化/物象化/留白/组词（"在客厅里走来走去""像生了锈的铁钉"）= 我把原材料摆出来，读者自己得出答案。读者参与了，文字就有余味。

这是冬小瓜六技（情绪动作化/留白/组词意象/客观对应物/优化迭代/落笔情感清单）的共同源头，也是所有高级文笔的根。

## 三个检验问句（任何段落都能用）

1. **我是在"告知"还是"呈现"？**
   告知 = "他很生气"（说明文）；呈现 = "他把杯子重重放下"（文学）。呈现优先。
2. **读者几步能得到这个意思？**
   0 步（直接看懂）→ 太平，要改；2–3 步（先看见画面，再自己想到情绪）→ 正好；5 步以上 → 太隐晦，往回拉。
3. **删掉这句，意思会不会反而更清楚？**
   会，就删（留白）。解释是留白的天敌。

## 文笔的四个层次（自下而上）

| 层 | 管什么 | 对应技巧 |
| --- | --- | --- |
| 词句层 | 选词与组合：动词/名词/通感/陌生化 | 组词意象、词句层进阶 |
| 表现层 | 情绪与画面的呈现方式 | 情绪动作化、客观对应物、落笔情感清单 |
| 结构层 | 节奏、密度、开篇、结尾 | 留白、结构层进阶、优化迭代 |
| 认知层 | 你到底想说什么（主题） | 先有想说的，文笔才有根 |

## 克制原则

- 技巧密度有上限：一段话 1–2 个亮点就够，全句花哨 = 油腻。
- 该直说的地方必须直说：结论句、金句、观点，直接给，不绕（绕 = 装）。
- 直抒比例：初稿可以 100% 直说（先把意思说清），定稿把直抒压到全文 1/3 以内，其余转呈现。

## 与文风的关系

- 文风 = 语法偏好（句式、视角、结构、情绪基调）→ 由 style-writer 决定"像谁"。
- 文笔 = 呈现质量（同一句话怎么写得好）→ 由本库决定"好不好"。
- 两者独立：独白体可以写得干巴巴，也可以写得出画面；随笔体同理。

## 举一反三的方向（本库衍生文件）

- 词句层进阶：动词升级、通感、陌生化、具体化（从"组词意象"推导）
- 结构层进阶：开篇钩子、长短句节奏、结尾留白、对话留白（从"留白"推导）
