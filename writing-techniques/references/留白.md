# 技巧：留白

来源：冬小瓜《文笔教学第十一期，留白》

## 核心
留白 = **把想象空间还给读者**。不把所有话说完，像魔术一样——给一个具体的意象/动作，让读者自己补上"背后是什么"。

## 操作步骤
1. 找出"把话说满"的地方（交代完结果、解释完感受）
2. 只保留**一个具体细节**，删掉解释和结论
3. 检查：读者看到这个细节，能否自行想到你要表达的意思？能，就成功了。

## 例句（实录）
- 想写"两个人已经分别了很久" → 不直说，写"耳边再听不到那声洪亮的老乡"（用"听不到的声音"暗示人已远去很久）
- 想写"距离与思念" → "想象到他跨越的空间和距离"
- 想写"落寞" → "掐灭了烟"（动作留白）
- 比喻：留白在我的感觉里像魔术；"这场魔术就尤其精彩"——好的留白让读者参与完成作品

## 检查
- [ ] 关键段落是否还有解释性的句子可以删？
- [ ] 删完后留下的细节是不是"能看见/能听到/能闻到"的具体物？
- [ ] 有没有给读者留"自己会心一笑"的空间？
