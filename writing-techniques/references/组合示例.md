# 组合示例：一篇随笔的技法分布

> 实战来源：《等待就是结果》（复联→被拒→看懂→止损→重建的真实经历改写）。示范"不同阶段用不同技法、混合穿插"，避免全文同一模板句。

## 全篇技法地图

| 段落 | 阶段 | 用的技法 | 关键句 |
| --- | --- | --- | --- |
| 开篇 | 引入 | 原文引用（双声部开场） | 引史铁生"结尾是什么？等待"→"我读到这里的时候，正在等一个人回消息" |
| 表白被拒 | 事件 | 白描动作 | "在对话框里删删改改，把自己想说的话发了出去""这句话我盯了很久" |
| 她的冷淡 | 观察 | 动作化 + 双声部扣合 | "问一句，答一句，从不反问，从不延伸"→ 扣引文"之后呢？没有之后" |
| 自我怀疑 | 情绪 | 场景 + 真实排比（自责） | "夜里翻聊天记录，一条一条对""是我太黏，是我话太多，是我让她烦了" |
| 装工具 | 转折 | 场景衔接（补动机） | "那几天我睡不踏实。手机翻来翻去……没什么特别的理由，就装上了" |
| 军师判断 | 认知 | 口语化转述（去术语） | "它回了一段话，我只记住一句：真想断干净的人，早就删了" |
| 截图事件 | 冲突 | 动作 + 停顿 | "写了一半，我停住了""我删掉了那段解释，回了两个字：好，我知道了" |
| 收藏 | 沉淀 | 引用自然浮现 | "回完那两个字，我忽然想起史铁生的一句话：有些事只适合收藏" |
| 重建清单 | 执行 | 清单直给（不评论） | "它列了一份清单：…" |
| 状态回望 | 变化 | 首尾回环 | "人空了一块"→"人空的那一块，被这些小事一点一点填回去的" |
| 画面收束 | 落点 | 画面 + 留白 | "路灯亮起来的时候，快门声很轻…也挺好的" |
| 结尾 | 翻面 | 结尾反转 + 金句托底 | "而我，还在等""等待就是结果""不，是秋天" |

## 四条可复用规则

1. **同层技法不连用**：相邻段落换手法（动作→场景→转述→清单→画面），读起来不腻。
2. **模板句限量**："不是A是B"类对比金句全文 ≤1 次；自我怀疑的三连排比只在情绪真实处用一次。
3. **引用要有来处**：引用要么被动作触发（"回完那两个字，忽然想起…"），要么被经历接住（"没有之后"扣她的回复），不硬插。
4. **金句即停**：金句说完立刻跳画面/动作，不补解释（"等待就是结果。第二天早上，闹钟响，我照常出门。"）。

## 用本示例

- 写完初稿后，对照地图检查：我的文章各阶段是否用了不同技法？
- 相邻两段手法相同 → 其中一段换成另一类（参考本地图的段落分布）。
