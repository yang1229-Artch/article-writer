# 技巧：优化迭代

来源：冬小瓜《文笔提升第七期-优化》

## 核心
"优化"最大的敌人是**因为写不出完美而迟迟不写**。正确路径：先记录（哪怕垃圾）→ 反复琢磨 → 每次只优化一点点 → 积少成多。文笔不是凭空起高楼，是水滴石穿。

## 操作步骤
1. 灵感来了先写下来，**不要边写边否定自己**
2. 初稿放一放，回头逐段改：每次只改一处（一个词、一句结构）
3. 一次改不动就换个角度（见其他技巧），改不动就留着，下次再碰
4. 长期：日常积累素材/阅读是优化前提，"优化就必须有水滴"

## 要点（实录）
- 症状："就是写不出来自己感觉完美的内容"→ 于是"就迟迟不写"
- 解法：先接受"写出来的是垃圾"，也要把它记录下来，然后去琢磨、去练
- 方法：每次能优化一点点，就够了
- 原则："而不是凭空起高楼"——优化基于已有素材，不是无中生有

## 检查
- [ ] 是否因为想一次到位而卡住？→ 拆小，一次只改一处
- [ ] 是否有素材/积累支撑这次优化？（没有就先补阅读/记录）
- [ ] 改后比改前好在哪，能否说出一处具体变化？
