# 技巧：落笔情感清单

来源：冬小瓜《文笔提升第九期-落笔实战》

## 核心
落笔写情绪时有抓手：**8 种基础情感**供选择，且**可以同时写两种情感**（复合情绪更真实，比如"喜悦里掺着嫉妒"）。

## 8 种情感清单
喜悦、悲伤、愤怒、恐惧、思念、嫉妒、愧疚、孤独

## 操作步骤
1. 先确定这段要写什么情感（从 8 种里选）
2. 尝试叠加第二种（主情感 + 副情感），制造层次
3. 用前面技巧落笔（情绪动作化/客观对应物/组词意象）
4. 欢迎展示自己的风格——情感表达没有标准答案

## 复合情感示例（构思方向）
- 喜悦 + 嫉妒：为朋友的成就高兴，又为自己没进步而落差
- 思念 + 孤独：想到一个人，周围越热闹越空
- 愧疚 + 释然：对不起的事放下了，但仍记得

## 检查
- [ ] 这段落笔前，是否明确知道情感是什么？（不是"说不清的感觉"）
- [ ] 是否尝试过叠加第二种情感？
- [ ] 主情感有没有被动作/物象/意象承载（而不是只用情绪词）？
