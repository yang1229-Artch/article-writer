# 技巧：情绪动作化（白描）

来源：冬小瓜《文笔教学第十期-如何描写情绪》

## 核心
情绪不要直白写（"我很烦""我很孤独"），通过**动作、台词、环境**让读者自己体会动作背后的情绪。

## 操作步骤
1. 圈出初稿里所有直说情绪的词（烦/难过/开心/失望/孤独/焦虑…）
2. 问自己：这个情绪会让人**做出什么动作、说出什么话、处在什么环境**？
3. 改写：删情绪词，写那个动作/台词/环境。

## 例句（实录）
- "我很烦" → "在客厅里走来走去"
- 紧张 → "他端着水杯的手指微微发颤"
- 烦躁/挫败 → "我撤下一片枯叶，反复地蹂躏，松开手掌，风一吹就散了"
- 白描要求：写出来要"让人看到画面"，可以借助环境（"环境里可以有什么"）

## 正反对照
- 反面："听完他的话，我感到心灰意冷"（直说）
- 正面："我陷入了许久的沉默" / "像几枚生了锈的铁钉"（见客观对应物技巧）

## 检查
- [ ] 全文还有几个直说情绪的词？
- [ ] 每个情绪是否都有对应动作？
- [ ] 动作是否具体到"能看见"（端着水杯的手/一片枯叶/走动），而不是"他很难受"？
