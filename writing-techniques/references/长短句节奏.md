# 长短句节奏（铺与砸）

> 实战反馈来源：用户对成稿的批评——"句子有点短凑，该简短简短，该生动时生动"，对照参考文章《奇怪的朋友》逐句分析后提炼。

## 一句话

**长句负责铺开，短句负责砸下。** 长句铺细节（场景/动作/物件），短句砸情绪（爆点/收束）。只有铺没有砸 = 流水账；只有砸没有铺 = 短凑。

## 诊断：短凑长什么样

- 通篇 2–8 字短句，读起来像敲木鱼，没有张弛
- 情绪全靠"砸"（短句直接说情绪），没有"铺"（画面/细节）托底
- 短句失去"特意"的分量——**全是钉子，就没有钉子了**

## 三原则

1. **场景/回忆处放开写（铺）**：长句装看得见的细节——动作、光线、声音、物件。"拇指划过去，屏幕亮一块、暗一块，她回的每一条都短得可怜。"让读者"看见"，而不是"知道"。
2. **情绪爆点保持短（砸）**：全文最重的地方字最少。"他哭了。""这句话我盯了很久。""好，我知道了。"——短句只有被长句衬着，才砸得响。
3. **段内节奏 = 铺-砸交替**：一段里长句铺完，短句收。段末短句收是标准动作，像呼吸（吸长、呼短）。

## 化虚为实（增强铺的力度）

抽象情绪 → 写成能看见/听见/摸到的东西。参照：
> "为什么？"这句话一直回荡在房间里，从他的眼泪流经我的身体。明明没有声音，但却一直加大频率不停回荡。

做法：抓住情绪，问三个问题——它像什么？它从哪里流过？它什么动静？
- 难过 → 眼泪堵在嗓子眼
- 困惑 → 问题在房间里回荡
- 空 → 人像被抽走一块
- 被占据 → 书里的东西把她挤出去

## 反例自查（写完全文过一遍）

- [ ] 通篇短句占比是否 >60%？（高于则短凑）
- [ ] 每段的"铺"（至少一处看得见的画面/动作）是否都在？
- [ ] 全文最重的那句话，是不是最短的那句？
- [ ] 短句是不是都在砸同一个情绪？（是则换成铺）
- [ ] 段末是否以短句收？
