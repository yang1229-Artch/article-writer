# 文笔打磨技巧库（writing-techniques）

## 是什么

一套把"白开水文字"改出画面感的技巧，来自冬小瓜文笔教学系列（第3/7/8/9/10/11期，已逐帧实录）。核心思路统一：**情绪和意义不直说，用可见的东西（动作、物象、留白、词的组合）让读者自己感受到。**

## 使用时机

- 用户说"文笔不好/写得太白/没有画面感/干巴巴/像AI写的"
- 用户要求润色、重写、打磨一段文字或一篇文章
- 任何成稿发布前做"去白水检查"

## 底层逻辑（先读这一个）

一切技巧共用一条根，见 `文笔底层逻辑.md`：**不替读者完成，只给原材料。** 三个检验问句："我在告知还是呈现？""读者几步能得到意思？""删掉这句是否更清楚？"——所有技巧都是这三问的落地方案。文笔分四层：词句层 → 表现层 → 结构层 → 认知层。

**两层理解**（写完全文都要过）：
- **第一层（结构）**：长短句铺-砸、母题变奏、金句位置——决定文章好不好看
- **第二层（人味）**：见 `人味七则.md`——示弱、闲笔、不闭合、毛边、扎一抚——决定文章像不像真人写的

## 工作流

1. **先写直白初稿**：把想说的意思完整写出来，不追求文笔（情绪可以直说，逻辑可以平铺）。
2. **定层定位**：先读 `文笔底层逻辑.md`，明确这段文字主要卡在哪一层（词句/表现/结构/认知），再挑对应技巧。
3. **逐项过技巧**（按文章内容挑适用的，不是全用）：
   - 情绪句 → 查 `情绪动作化.md`：直说情绪的地方改成动作/台词/环境
   - 关键场景 → 查 `留白.md`：把话说满的地方改成收住，留想象空间
   - 重要意象 → 查 `组词意象.md`：平淡的词组换成两个反差词组合
   - 抽象感受 → 查 `客观对应物.md`：给主观情感找一个可看见的物象
   - 词句偏弱 → 查 `词句层进阶.md`：动词升级、通感、陌生化、具体化
   - 结构偏平 → 查 `结构层进阶.md`：开篇钩子、长短句节奏、结尾留白、对话留白
   - 读着"短凑"/没有张弛 → 查 `长短句节奏.md`：长句铺、短句砸，铺-砸交替（用户实战反馈沉淀）
   - 读着"太像 AI/没有活人气" → 查 `人味七则.md`：示弱、闲笔、不闭合、毛边、扎一抚（样本深读提炼）
   - 技法不知怎么组合 → 查 `组合示例.md`：一篇完整随笔的技法分布地图（不同阶段用不同手法）
   - 改不动/越改越糟 → 查 `优化迭代.md`：别憋大招，记录下来每次只优化一点点
   - 缺情感层次 → 查 `落笔情感清单.md`：确认情感是否单一，可叠加两种
4. **过检查表**（见下）。
5. **交付**：改前/改后对照 + 用到的技巧说明 + 底层逻辑命中说明。

## 检查表（发布前过一遍）

- [ ] 这段是在"告知"还是在"呈现"？（底层逻辑第一问）
- [ ] 情绪词（烦/难过/开心/孤独/失望…）是否还有可改的动作或物象替代
- [ ] 关键句子是否话说得太满，可否删半句留白
- [ ] 意象是否停留在"好看""温暖""沉重"这类标签词
- [ ] 每段有没有一处"能看见画面"的细节
- [ ] 第一句是否给了画面/反常/悬念，而不是交代背景
- [ ] 段落是否长短句交替、段末有短句收
- [ ] 结尾是否停在画面/动作上，没有总结升华
- [ ] 直抒部分是否少于全文 1/3（初稿直说、定稿转写）

## 规则

- 技巧是手段不是目的：**该直说的地方直说**（结论句、金句、观点），全篇技巧会堆砌。
- 每个技巧例句来自教学实录，可复用句式，不复用内容。
- 与 style-writer 配合：style-writer 定文风（写得像谁），本库定文笔（怎么写得好）。
