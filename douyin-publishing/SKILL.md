# 抖音长图文发布实战（douyin-publishing）

## 是什么

长图文文章写完之后到发布之间的一整套护航动作。长图文的"图"是文字的载体（排版页），不是视觉主体：文章写得好 ≠ 会火，封面题头、分屏钩子、排版统一、互动收藏引导各占一分。本库把"发布前必须想的五件事"固化成流程。

## 使用时机

- 定稿后：用户问"配什么图""封面怎么配""怎么发""能不能火"
- 发布前：走一遍"五件套"核查
- 发布后：按数据（完读/收藏/评论）复盘，反馈回流到写作三库

## 工作流（定稿后五件套）

1. **脱敏核查**：先查红线再谈传播——读 `references/脱敏红线.md`，逐项确认（截图打码、原话保留、对方可识别信息、发布范围）。
2. **配图方案**：读 `references/配图方案.md`，按长图文排版法给每屏方案（文字切分+排版参数+氛围元素；不生成图，用户自排）。
3. **发布策略**：读 `references/发布策略.md`，给封面题头方案、标题候选、分屏钩子、发布时间、标签、互动+收藏引导。
4. **爆款预判**：读 `references/爆款分析.md`，六维评估+四卡点（封面题头/完读率/互动收藏/标题），诚实给评级和条件（不保证爆）。
5. **发布与复盘**：发布动作由用户执行；发布后按数据把新经验回流到三库。

## references/ 结构

| 文件 | 管什么 | 关键结论 |
| --- | --- | --- |
| `脱敏红线.md` | 隐私与安全 | 截图必打码；原话保留需用户拍板；不泄露对方可识别信息 |
| `配图方案.md` | 每屏配什么图 | 长图文排版法：图=文字载体；AI只给方案用户自排；一屏≤200字 |
| `发布策略.md` | 怎么发才有人看 | 封面=文章题头；分屏钩子保完读；结尾互动+收藏引导 |
| `爆款分析.md` | 能不能火 | 六维评估+四卡点；完读率/收藏率优先；不承诺结果 |
| `长图文实战示例.md` | 完整分屏样例 | 《等待就是结果》12 屏方案 + 六条可复用规则 |
