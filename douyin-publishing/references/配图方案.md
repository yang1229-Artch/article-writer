# 配图方案（长图文排版法）

> 长图文的"图"是**文字的载体**，不是视觉主体。本库管"每屏文字怎么切分 + 怎么排版"。**AI 不做图**（文字渲染不可控），AI 给方案，用户用排版工具（醒图/Canva/PPT）自己做——这才是长图文该有的分工。

## 核心认知（和卡片式图文的区别）

| | 卡片式图文 | 长图文（本库） |
| --- | --- | --- |
| 主体 | 图，文字点缀 | 文字，图是衬底 |
| 每屏 | 一个视觉冲击 | 一段文字（100–200 字） |
| 阅读 | 快速划过 | 逐屏滚动，像读文章 |
| 配图 | 找意象图 | 排版设计 |
| 谁来做 | AI 生图可做 | **用户排版**（AI 只给方案） |

## 长图文结构（8–12 屏为宜）

```
屏1 封面（第0屏）→ 正文屏（每屏一段）→ 金句屏（1-2屏）→ 结尾互动屏
```

- 封面：标题 + 钩子原话，像"文章标题页"（信息流里点不点看它）
- 正文屏：一屏一段，段末留半句悬念（分屏钩子），下一屏接——这是完读率的命根
- 金句屏：全文只 1–2 屏单独放大金句，做阅读呼吸点
- 结尾屏：金句收尾 + 评论区互动引导

## 每屏排版三要素

1. **背景**：纯色/极浅渐变/低饱和氛围图。全系列锁死一套（如秋日暮色暖调）。背景是情绪，不抢字。
2. **文字**：衬线（宋体/楷体）或手写体更"随笔"；字号大（手机端 40–60px 级别）、行距舒展、字距适中；一屏文字不超过 200 字，多了读者放弃。
3. **留白**：四边留 15–20%；段间有呼吸。留白=高级感，满=压迫。

## 氛围元素（克制使用）

- 一屏最多一个意象（落叶/路灯/手机/书/长椅），放在背景或角落，不居中抢字。
- 意象跟着内容走：讲"等消息"放手机/路灯，讲"收藏"放抽屉/枯叶，讲"清单"放纸条特写。
- 全系列 2 个母题反复出现（如手机=等，路灯=天会亮），首尾呼应。

## 工具建议

- 排版工具：醒图 / Canva / 手机备忘录截图 / PPT 导出图。任一即可，关键是统一字号、字色、背景色。
- 背景图来源：自己拍（真实感最强）或无版权图库（Pexels/Unsplash，搜"黄昏 路灯""秋天 长椅"等）。
- 不要用 AI 生图直接当长图文成品——AI 渲染长段文字易错字、排版不可控；AI 的正确用法是生成背景氛围图（无文字）供衬底。

## 输出格式（给用户的方案长这样）

```
屏1 封面：标题"XX" + 钩子"XX" ｜ 背景：XX ｜ 氛围：XX
屏2 正文：〔文字切分示意〕 ｜ 背景：XX ｜ 末尾钩子：XX
...
```

## 反例自查

- [ ] 全系列背景/字体/字号是否统一？
- [ ] 每屏文字是否 ≤200 字、是否只讲一件事？
- [ ] 每屏结尾是否有"划下去的理由"（半句悬念）？
- [ ] 是否每屏只有 0–1 个氛围元素？
- [ ] 金句屏、结尾互动屏是否都有？
- [ ] 有没有给"排版工具 + 统一参数"的具体建议？
