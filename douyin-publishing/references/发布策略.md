# 发布策略（怎么发才有人看）

> 定稿之后、发布之前的传播设计。长图文逻辑：封面像文章标题页（决定点不点），分屏钩子决定完读率，收藏率比点赞率更值钱。

## 长图文 vs 短图文（先分清再谈策略）

| | 短图文 | 长图文（本库优先） |
| --- | --- | --- |
| 封面 | 视觉冲击/大字钩子 | 文章标题页（标题+副标，像一篇文章的题头） |
| 核心指标 | 前 3 秒点击率 | 完读率、收藏率 |
| 标题 | 原话钩子优先 | 原话钩子 + 信息量（读者要知道"这是一篇什么文章"） |
| 互动 | 评论引导 | 评论引导 + 收藏引导（"先收藏，等一个人回消息时再看"） |

## 标题策略（信息流场景）

- **原话即钩子 > 文艺意象**：一句真实原话（"她说'现在不想谈恋爱'"）比文艺标题（《等待就是结果》）点击率高。文艺标题留给内页金句屏，封面用原话。
- 给 2-3 个标题候选，按信息量排序：原话型 > 结果型 > 问题型 > 文艺型。
- 标题 ≤15 字；具体时间、日期一律隐去（隐私 + 信息流不需要）。

## 封面策略（第 0 屏）

- 长图文的封面 = **文章题头**：主标题（记忆点金句）+ 副标（交代"这是关于什么的"，如"我花了一个月，才学会等待"）。
- 主标题用全文可截图转发的金句（如"等待就是结果"）；副标放最扎心的原话（如"她说，现在不想谈恋爱"）。
- 别把升华引用（史铁生名句）放封面——那是内页的升华。
- 封面自己配（用户偏好），AI 只给文字方案：主标题一句话 + 副标一句话 + 背景/氛围建议。

## 分屏钩子（长图文完读率的命根）

- 每屏结尾留半句悬念/未完待续，读者才划下一屏。示例："她给我的每一句回复，都像这句对话里的'没有之后'——"（下一屏接"说完就没了，不接话，不留门"）。
- 总屏数 8–12 为宜；超过 12 屏完读率断崖。
- 中段安排 1 个金句屏（无正文，大字单句），给视觉呼吸，也抬收藏率。

## 互动钩子（必做）

- 结尾必须有评论区引导，围绕全文记忆点提问。示例："你也有过'等一个人回消息'的时候吗？后来你等到了什么？评论区聊聊。"
- 长图文加一句收藏引导："建议先收藏——下次等一个人回消息的时候，再打开看看。"
- 互动问题要"能回答"：读者一句话就能接，不要问需要长篇回答的问题。

## 发布参数

- **时间**：21:00–23:00（情感/成长内容阅读高峰）。
- **标签**：3-5 个，结构 = 平台大标签（#情感 #成长）+ 内容标签（#等待 #自我成长）+ 垂类标签（#AI工具 #随笔）。不用冷门自造词。

## 记忆点

- 全文只留一个"可截图转发"的金句（如"等待就是结果"）——封面、金句屏、结尾反复出现它，读者截图/收藏传播的就是它。

## 交付格式

给用户时按固定格式输出：
```
标题候选（2-3 个，按信息量排序）
封面方案（主标题+副标+背景氛围）
分屏钩子检查（每屏结尾的悬念句）
发布时间 + 标签 + 互动钩子（含收藏引导）
```
