# 爆款分析（能不能火）

> 诚实评估，不承诺结果。给评级、给卡点、给条件——让用户知道"差在哪、怎么补"。长图文优先看**完读率与收藏率**，短图文看点击率与互动率。

## 六维评估（每维 ★ 1-5）

| 维度 | 看什么 | 高分标志 |
| --- | --- | --- |
| 选题流量池 | 内容落在哪个赛道 | 情感/成长/职场/搞钱等大流量池 |
| 情绪曲线 | 起承转合是否完整 | 共鸣→悬疑→爽点→治愈→升华，五段不缺 |
| 差异化 | 有没有别人抄不走的东西 | 真实细节、独家素材、新奇装置（如 AI 工具）、文化纵深（如引用） |
| 真实性 | 细节可信度 | 原话、具体动作、具体时间感——AI 写不出的颗粒 |
| 传播性 | 金句能否截图转发 | 有一句"可带走"的话 |
| 互动设计 | 评论区能否滚起来 | 结尾有引导问题，读者一句话能接 |

## 四卡点自查（长图文最容易翻车的地方）

1. **封面（第 0 屏）**：长图文的封面是"文章题头"——没有标题感、看不到信息量，读者不点。文艺感封面 + 无信息量标题 = 两头弱，必翻车。
2. **完读率**：总屏数 > 12 屏断崖；每屏文字 > 200 字断崖；屏与屏之间没有"划下去的理由"（分屏钩子）断崖。这是长图文的头号命门。
3. **互动/收藏钩子**：没有评论区引导 → 互动量上不去；没有收藏引导 → 收藏率浪费（长图文靠收藏传播）。
4. **标题信息量**：标题太文艺（无信息量）→ 点击全靠封面；封面也文艺 → 没人点。

## 长图文 vs 短图文评级差异

| 指标 | 短图文权重 | 长图文权重 |
| --- | --- | --- |
| 封面点击率 | 高 | 高（题头感） |
| 完读率 | 中 | **最高**（分屏节奏） |
| 收藏率 | 低 | **高**（被收藏=被传播） |
| 评论率 | 高 | 中 |
| 转发率 | 中 | 中 |

## 输出格式

```
一句话判断（有机会/难/不建议发 + 一句理由）
六维评级表
卡点清单（命中的 + 怎么补）
优化动作（3 条以内，按优先级）
```

## 诚实原则

- 不保证爆。给的是"条件达成概率更高"，不是"必火"。
- 评级是方向参考，不是预言；发布后的数据（完读/点赞/评论/转发/收藏）才是最终答案。
- 数据复盘后，把"哪种封面/分屏钩子/标题有效"的新经验回流到本库和三库——这就是迭代。
