# 写作自查与去AI味（writing-review）

## 是什么

一套"AI 味识别 → 正向替换"的自查方法，来自实战中用户逐句挑出的 AI 味重灾区。核心原则：**AI 味 = 把结构暴露给读者（过渡、总结、解释、模板、正确、有用、闭合），人味 = 让内容自己流过去（状态、动作、画面、留白、露怯、无用细节、问号）。**

## 使用时机

- 用户说"哪里像 AI""写得太 AI 了""帮我自查一遍""审一遍稿子"
- 任何成稿发布前过一遍本清单
- 写完初稿、准备打磨时

## 工作流

1. **读全文，逐段标记 AI 味特征**（对照 `ai味自查清单.md` 的 10 条，在稿子上标出命中的句子）。
2. **按"正向替换表"改**（每条命中特征 → 对应替换法，见清单文件）。
3. **技法多样性检查**：确认相邻段落用了不同手法（白描/场景/对话转述/清单直给/画面/引用回环…），同一模板句（尤其"不是A是B"）全文不超过 1 次。
4. **高级结构检查**：需要提升味道时，查 `高级结构技法.md`（双声部复调/首尾回环/结尾反转），按需套用。
5. **交付**：改前/改后对照 + 命中特征清单 + 使用技法说明。

## 快速版自查（10 秒版）

- [ ] 有没有"想通了还不够""接下来""最难的是"这类逻辑过渡？
- [ ] "不是A是B"句式出现几次？
- [ ] 结尾有没有总结升华（"原来真正…"）？
- [ ] 有没有"没想到…""帮了大忙"预告式口吻？
- [ ] 引用是不是硬插的（"XX还说过"无来处）？
- [ ] 金句后面有没有跟着三句解释？
- [ ] 有没有具体日期/时间段堆砌（前天/一个月后/五年前）？
- [ ] 叙述者是不是"永远正确"？有没有一处露怯（"我也说不上来"）？
- [ ] 有没有至少一个与主线无关的"没用"细节（闲笔）？
- [ ] 结尾是留了问号/沉默，还是强行"想通了"闭合？

## 规则

- 用户明确的风格偏好优先于技巧（标题要短、时间要隐、结尾要留白等）。
- 真实优先：金句、细节、转述必须来自真实素材，不演绎、不编造（军师的话就用军师真实说过的）。
- 与 writing-techniques 分工：那边教"怎么写得好"（词句/表现/结构），本技能管"哪里像 AI、怎么去"。
