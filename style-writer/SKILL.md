# 文风写作（style-writer）

## 是什么

把已提取的中文自媒体文风固化为「风格卡 + 样本原文」的库。写作流程：选卡 → 读样本找语感 → 按卡写 → 去 AI 味检查。风格卡抓的是可复制的骨架（句式/结构/视角/节奏/情绪质地），文笔的味道靠样本原文校准，两者缺一不可。

## 风格库（references/）

| 风格卡 | 文笔质地 | 触发场景 |
| --- | --- | --- |
| `风格卡-对话金句体.md` | 双人对话剧本，一问一答推进，金句密集 | 恋爱观、友情、关系洞察；"朋友问我…"式内容 |
| `风格卡-心理剖析独白体.md` | 第一人称贴着皮肤，长句铺陈+短句砸点 | 个人经历复盘、情绪成长、深夜独白 |
| `风格卡-现实论证体.md` | 冷静旁观者，排比压阵+概念收束 | 男女现实、社会观察、扎心真相 |
| `风格卡-方法论体.md` | "姐姐式"叮嘱，分点递进 | 恋爱技巧、处世方法、步骤干货 |
| `风格卡-故事叙事体.md` | 小说化叙事，有镜头、台词、停顿 | 职场故事、亲身经历、人物特写 |
| `风格卡-干货清单体.md` | 导师口吻，小标题+分条+建议句 | 知识整理、实用指南、说理文章 |
| `风格卡-第二人称劝诫体.md` | 全程"你"字直面读者，密集排比+认知转折 | 野心、努力、创业、自我要求；"写给正在…的你" |
| `风格卡-意象散文体.md` | "我们"视角抒情散文，意象铺陈+对仗排比 | 缘分、错过、遗憾、成长感悟；结尾短句收束 |
| `风格卡-随笔杂文体.md` | 说话式随笔，允许跑题，真实承认窘迫 | 个人絮叨、圈内吐槽、自我和解；结尾停在画面或感叹 |
| `风格卡-认知长文体.md` | 认知成长史（信→疑→验），概念落成人话+幽默自嘲 | 知识科普、哲学概念、历史解读、深度长文 |

## 工作流

1. **定风格**：用户说"按 XX 风格写"→ 在风格库找对应卡；用户没指定 → 用上方决策表选卡；用户给的风格不在库里 → 先走"新增风格卡"蒸馏入库。
2. **读卡 + 读样本**：读对应 `references/风格卡-*.md` 全文；再从 `references/samples/` 读 1–3 篇该风格原文，校准语感（句子怎么接、何时用短句、情绪藏在哪）。只凭风格卡下笔 = 写出骨架没有味道。
3. **按卡写**：命中卡的句式骨架（如"不是…而是…"）、结构模板、视角距离、节奏和情绪质地。复刻写法，不复刻内容——样本里的事件、观点、经历不能搬进新文章。
4. **打磨与自查**：写完交给流水线下一步——文笔打磨走 `writing-techniques`（读其 SKILL.md 与 `references/文笔底层逻辑.md`，按技巧逐项过）；去 AI 味走 `writing-review`（读其 SKILL.md 与 `references/ai味自查清单.md` 逐段标记→替换）。本技能不再自带去 AI 味清单，避免三库重复。
5. **交付**：成品 + 命中说明（用了哪些风格特征）+ 事实核对清单（哪些来自用户素材、哪些是展开创作）+ 打磨/自查记录。

## 新增风格卡（蒸馏）

用户提供新博主文章（链接/粘贴/文件）时：

1. **读全文**：抖音等平台链接用浏览器读取正文（含图片里的文字）；粘贴/文件直接读。
2. **六维分析**，每维度记特征不记内容：
   - 语言指纹：句长、口头禅、高频句式、标点习惯
   - 结构模板：开头钩子、正文骨架、结尾方式
   - 选题与禁区：写什么、不写什么
   - 素材偏好：亲身经历/对话/数据/引用
   - 认知框架：反复出现的核心命题 3–5 条
   - 视觉呈现：排版、配图、图文协作
3. **写风格卡**：`references/风格卡-<对象>-<子类型>.md`，一页内（≤800 字），含：文笔质地、视角距离、节奏、结构、情绪、3 条"照着写就会像"、3 条"写了就像别人"。
4. **存样本**：原文全文存 `references/samples/<对象>-<编号>.md`，文件名 `对象-编号.md`。
5. **更新风格库表**（上表加一行）。

## 规则冲突时

用户明确指令（主题/平台/长度）> 风格卡结构 > 风格卡语言与视角 > 认知框架。

## 与其他技能的关系

- 本技能只定**文风**（像谁）。文笔打磨交给 `writing-techniques`，去 AI 味自查交给 `writing-review`。
- 三库完整流水线见 article-writer 的 `references/复合写作工作流.md`（四步：定风格→初稿→打磨→自查→总验收）。
