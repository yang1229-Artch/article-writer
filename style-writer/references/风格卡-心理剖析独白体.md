# 风格卡：心理剖析独白体（Zayne ①）

## 文笔质地
第一人称贴着皮肤，气息绵长，像深夜自己跟自己说话。脆弱是真的，清醒也是真的。

## 核心参数
- 视角距离：零距离，读者坐在他心里
- 节奏：长句铺陈情绪 → 短句砸点（"关系像一面镜子"）；段落短但句子长
- 结构：转述/场景引入 → 一句核心观点 → 旧认知（"我以为…"）→ 转折（"后来我发现…"）→ 三层剖析（暴露→需求→边界）→ 转变（"真正的转变是从承认…开始的"）→ 升华收尾
- 情绪：自我对话式的觉察，先承认脆弱，再给出清醒
- 句式骨架："不是…而是…"（论点推进）；"我会在…会在…也会在…"（排比铺情绪）；"我开始…"（转变标记）；具体行为写抽象情绪（"在对方迟迟不回消息时反复猜测"）

## 金句模式
"关系像一面镜子，但它不是那种平整清晰的镜子，更像一块带着纹理的水面"
"亲密不是紧紧抓住对方，而是保持自我完整的前提下，与另一个同样完整的人共振"

## 照着写就会像
1. 每段第一句用"我"起手，先写具体行为再给情绪（先"翻聊天记录"，后"觉得不被重视"）
2. 用"不是…而是…"推进每一个认知转变
3. 结尾往"更真实的自己"升华，不给读者提建议

## 写了就像别人
1. 出现"首先/其次/总的来说"
2. 出现数字、案例、引用数据
3. 口语段子腔或网络梗
