# 文风提取与迁移

## 什么时候用本指南

用户要求"照这个风格写""学这个博主的调性""用我自己的语气""别写得像 AI""模仿 XX 的文风"时命中。流程分两步：**先提取**（把风格从样本里蒸馏成可复用的规则），**再迁移**（按规则写出新内容）。不提供风格对象时跳过本模块，直接按平台指南写。

## 一、提取：三步出风格卡

### 第 1 步：收集样本

- **数量**：个人号/短视频文案 8–12 篇即可；长文作者 15–20 篇。
- **范围**：同一账号/作者不同时期、不同类型的内容（干货/种草/情绪分享/故事），避免只收同一种。
- **格式**：原文存为 `.md` 或 `.txt`，文件名 `YYYY-MM-DD 类型 标题.md`。
- **图片内容必须看**：抖音图文的截图、聊天记录、对话本身就是风格的一部分，也是论证链的承重结构。逐张打开，记录图片在叙事里承担的角色（证据型/演示型/数据型/叙事推进型/情绪型）。

### 第 2 步：六维分析（对每篇样本过一遍，记特征，不记内容）

| 维度 | 看什么 | 记什么 |
| --- | --- | --- |
| **L1 语言指纹** | 句长、断句、用词、口头禅、标点习惯 | 高频词、口头禅、短句占比、爱用的符号（…/！/？）、口语化程度 |
| **L2 结构模板** | 开头怎么抓人、中间怎么推进、结尾怎么收 | 开头类型（场景/提问/结果/悬念）、正文骨架（时间线/清单/情绪曲线）、结尾方式（收束/互动/自然结束） |
| **L3 选题与禁区** | 写什么、不写什么、什么时机写 | 选题判断标准、话题禁区 |
| **L4 素材偏好** | 靠什么撑内容：亲身经历/截图/数据/别人的话 | 素材类型清单、证据型截图的使用方式 |
| **L5 认知框架** | 反复出现的观点、价值判断、对读者说的话 | 核心命题 3–5 条 |
| **L6 视觉呈现** | 排版、配图、字压图、色系 | 图文协作模式、每张配图的内容类型、视觉元素清单 |

### 第 3 步：产出风格卡（一页纸内，≤800 字）

```
风格卡：<对象>
语言指纹（L1）：…
结构模板（L2）：…
选题与禁区（L3）：…
素材偏好（L4）：…
核心认知（L5）：…
视觉呈现（L6）：…
3 条"照着写就会像"的可执行规则
3 条"写了就像别人"的禁忌
```

**自检**：把风格卡给一个没读过样本的人，他能写出 ≥7/10 近似度的内容 → 合格。写不出 → 回第 2 步补维度，或加样本。

## 二、迁移：按风格卡写

### 写作前必读

1. 风格卡全文。
2. 3–5 篇与本次体裁和题材最接近的样本原文——目的是校准语感（句子怎么接、什么时候突然用一个短句），**不是找素材**。

### 优先级（规则冲突时按此取舍）

1. 用户本次指令（题材、平台、长度、语言）
2. L2 结构模板中匹配当前体裁的那一套
3. L1 语言指纹 + L6 视觉呈现
4. L5 认知框架（决定观点立场和素材选择，不决定句式）

### 硬规矩

- **复刻的是写法，不是内容**：样本里的观点、事实、经历不能搬进新文章。
- 写完后必须过一遍"去 AI 味检查"。

## 三、去 AI 味检查（发布前逐项过）

| 检查项 | 具体做法 |
| --- | --- |
| 套话/假大空 | 删掉"赋能""闭环""仪式感拉满"这类空词 |
| 排比三连 | 打破"不仅…而且…更是…"式排比，长短句交错 |
| 过度升华 | 结尾不用"让我们…吧"式口号，用一句具体的话收 |
| 过度工整 | 允许口语、碎句、一个词成段，不追求每段都四平八稳 |
| AI 常用过渡 | "首先/其次/最后"换自然衔接；"总的来说"直接删 |
| 感叹号堆砌 | 一段最多一个 |
| 内容保真 | 数字、事实、引语逐条核对；去 AI 味不许改内容 |

## 四、和类型路由表配合

写抖音/小红书/公众号时：

- 用户给了"风格对象"（自己的旧文、喜欢的博主、指定的作者）→ 先跑提取 → 迁移，再按对应平台指南的篇幅和结构收口。
- 用户没给风格对象 → 直接按平台指南写，跳过本模块。

## 五、风格卡的复用

风格卡存为独立 `.md` 文件，命名 `风格卡-<对象>.md`。再次写同对象内容时，直接读卡 + 对应样本，不用重新提取。
