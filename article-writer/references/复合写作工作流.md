# 复合写作工作流（三库流水线）

> 本文件把三个写作子技能串成一条流水线。任何"想写得好、不像 AI"的文章都走这条路。三个子技能在 `.user_skills` 中：style-writer（文风）、writing-techniques（文笔）、writing-review（去AI味/自查）。

## 何时走本流水线

- 用户要求"按 XX 风格写""写得好一点""别像 AI""要文笔""要深刻"
- 情感类、个人经历类、观点类文章的正式写作
- 简单告知类文案（通知、回复、一句话说明）不走此线，直接按平台指南写

## 流水线（四步）

```
① 定风格（style-writer）→ ② 写初稿 → ③ 打磨文笔（writing-techniques）→ ④ 去AI味自查（writing-review）→ 总验收
```

### ① 定风格

- 用户指定风格/博主：Read `style-writer/SKILL.md` → 查风格库 → 读对应风格卡 + 1–3 篇样本原文校准语感
- 用户未指定：用"选题→风格卡快速决策表"（见 style-writer/SKILL.md）
- 风格不在库：按 style-writer 的"新增风格卡"蒸馏入库后再写

### ② 写初稿

- 按风格卡骨架写"直白初稿"：把意思说全，不追求文笔
- 只复刻写法，不复刻内容（样本事件/观点/经历不可搬用）
- 涉及用户真实经历时：只用素材库/会话档案里的真实细节，不演绎金句（军师的话用军师真实说过的）

### ③ 打磨文笔（writing-techniques）

- Read `writing-techniques/SKILL.md` 与 `references/文笔底层逻辑.md`
- 按"底层逻辑三问"定位问题层（词句/表现/结构/认知）
- 挑对应技巧逐项过；注意**不同阶段用不同技法**（白描/场景/对话转述/清单直给/画面/引用回环…），同一模板句全文 ≤1 次
- 组合用法参考 `writing-techniques/references/组合示例.md`

### ④ 去AI味自查（writing-review）

- Read `writing-review/SKILL.md` → 用 `references/ai味自查清单.md` 逐段标记→替换
- 需要提升味道时套用 `references/高级结构技法.md`（双声部/回环/反转）
- 与步骤③有重叠时：③管"写得好不好"，④管"像不像 AI"，先③后④

## 总验收单（发布前逐项过）

| # | 验收项 | 标准 |
| --- | --- | --- |
| 1 | 标题 | ≤15 字、有钩子（画面/反常/悬念/原话） |
| 2 | 隐私脱敏 | 无真实姓名/可识别信息/聊天截图；用户要求保留的原话需用户拍板 |
| 3 | 事实真实 | 时间已按用户要求隐去；数字/引语有据；金句来自真实素材不演绎 |
| 4 | 文风命中 | 与所选风格卡一致；复刻写法未复刻内容 |
| 5 | 文笔达标 | 有 ≥2 处"能看见的画面"；情绪无直抒过度；技法混用 |
| 6 | 无 AI 味 | 过 writing-review 快速自查（逻辑过渡/对比模板/总结结尾/预告口吻/硬插引用/层层解释） |
| 7 | 篇幅 | 符合目标平台（抖音图文 800–1500 字，分屏可读） |

## 交付说明

- 成品 + 风格命中说明 + 技法使用说明 + 事实/隐私核对清单
- 文章发布前，第 2、3 项需用户最终确认
