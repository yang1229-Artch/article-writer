# 小红书图文笔记

## 特点

- 小红书是种草社区：标题＋封面＋正文＋标签，正文口语、亲切，支持换行和 emoji。
- 标题带关键词，利于搜索；封面建议 3:4 竖图。

## 结构模板

1. **标题**：15–25 字，带关键词和钩子。
2. **封面**：3:4 竖图，叠加大字标题。
3. **正文**：开头 1–2 句场景 → 分点干货（emoji 分段）→ 结尾引导（收藏、评论区）。
4. **标签**：5–10 个，前 3 个为核心关键词。

## 写法要点

- 口语化、有真人感，例如"我是真的试过才敢说"。
- 干货类用"数字＋要点"，如"3个方法""5个避坑"。
- 每段 2–3 行，多用换行和 emoji 做视觉节奏。
- 不夸大效果；慎用"最、第一、绝对"等极限词。

## 示例骨架（好物/工具安利型）

- 标题：装了两个开源AI技能后，我的生活变了
- 封面：大字"AI生活军师"＋截图拼图
- 正文：开头场景 → 技能1是什么、怎么用 → 技能2是什么、怎么用 → 我的真实变化 → 安装方法一句话
- 标签：#AI工具 #效率工具 #开源 #自我提升
