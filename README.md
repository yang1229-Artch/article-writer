# article-writer · 文章写作技能

一个给 AI 助手使用的中文文章写作 Skill：把想法、经历、素材加工成可直接发布的中文文章，覆盖抖音图文、小红书图文、公众号文章、短视频分镜脚本和一般文章。

## 它能做什么

| 场景 | 说明 |
| --- | --- |
| 抖音图文笔记 | 封面建议 + 正文要点 + 配图建议 + 话题标签 |
| 小红书图文笔记 | 标题 + 封面 + 干货正文 + 标签 |
| 微信公众号文章 | 标题 / 导语 / 分段结构 / 结尾 |
| 短视频分镜脚本 | 分镜表（镜号、时长、景别、画面、口播、字幕） |
| 一般文章 / 随笔 | 钩子开头 + 分段结构 + 行动收尾 |

## 安装方法

把本仓库的 `article-writer/` 文件夹复制到你的 AI 技能库即可。以豆包为例：

```
目标位置：<技能库根目录>\.user_skills\article-writer\
```

或者在支持 Skill 的 AI 助手里直接说："帮我安装 GitHub 上的 article-writer 技能"。

## 使用方式

安装后，直接告诉 AI 你要写什么，例如：

- "写一篇抖音图文，主题是：……"
- "用文章写作技能，把我的经历写成小红书笔记"
- "做一个公众号文章 + 短视频脚本"

AI 会先确认平台类型，再按对应平台的规范输出成品，并附封面建议、配图建议、话题标签和事实核对清单。

## 项目结构

```
article-writer/
├── article-writer/         技能本体（SKILL.md + references）
│   ├── SKILL.md            核心规则：触发描述、工作流、类型路由表
│   └── references/         分平台写作指南（按需加载）
└── README.md               本说明
```

## 设计原则

- **真实优先**：只用用户提供的素材和可核实事实，不虚构数据或效果。
- **先定类型再动笔**：不同平台的结构、篇幅、语气完全不同，先路由再写。
- **钩子开头**：第一句决定读者留不留。
- **渐进式披露**：SKILL.md 精简，平台细节放 references 按需读取。
