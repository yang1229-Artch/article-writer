# article-writer · 中文写作技能体系

一套给 AI 助手使用的中文写作技能：把想法、经历、素材加工成可直接发布的文章。覆盖抖音长图文、小红书图文、公众号文章、短视频分镜脚本和一般文章，并由四个子技能分别解决"写得像谁、怎么写得好、怎么不像 AI、怎么发得出去"。

## 它能做什么

| 场景 | 说明 |
| --- | --- |
| 抖音图文笔记 / 长图文 | 封面建议 + 正文要点 + 配图建议 + 话题标签 |
| 小红书图文笔记 | 标题 + 封面 + 干货正文 + 标签 |
| 微信公众号文章 | 标题 / 导语 / 分段结构 / 结尾 |
| 短视频分镜脚本 | 分镜表（镜号、时长、景别、画面、口播、字幕） |
| 一般文章 / 随笔 | 钩子开头 + 分段结构 + 行动收尾 |

## 四个子技能

| 技能 | 解决什么 |
| --- | --- |
| `style-writer/` | 文风库：10 张风格卡 + 11 份样本原文，按博主风格写作 |
| `writing-techniques/` | 文笔库：情绪动作化、留白、组词意象、客观对应物、长短句节奏、人味七则 |
| `writing-review/` | 去 AI 味库：13 条 AI 味自查清单 + 正向替换 + 高级结构技法 |
| `douyin-publishing/` | 发布实战库：脱敏红线、配图排版、发布策略、爆款分析 |

## 安装方法

把本仓库的 `article-writer/`、`style-writer/`、`writing-techniques/`、`writing-review/`、`douyin-publishing/` 五个文件夹复制到你的 AI 技能库即可。以豆包为例：

```
目标位置：<技能库根目录>\.user_skills\（五个文件夹平级放入）
```

## 使用方式

安装后，直接告诉 AI 你要写什么，例如：

- "写一篇抖音长图文，主题是：……"
- "用文章写作技能，把我的经历写成小红书笔记"
- "按这个博主的风格写一篇"（走 style-writer 文风库）

AI 会先确认平台类型，再按对应平台的规范输出成品，并附封面建议、配图建议、话题标签和事实核对清单。

## 项目结构

```
article-writer/
├── article-writer/         总入口（SKILL.md + references，含复合写作工作流）
├── style-writer/           文风库（风格卡 + 样本原文）
├── writing-techniques/     文笔库（技巧 + 人味七则）
├── writing-review/         去 AI 味库（13 条自查清单）
├── douyin-publishing/      发布实战库（长图文方向）
└── README.md               本说明
```

## 设计原则

- **真实优先**：只用用户提供的素材和可核实事实，不虚构数据或效果。
- **先定类型再动笔**：不同平台的结构、篇幅、语气完全不同，先路由再写。
- **钩子开头**：第一句决定读者留不留。
- **渐进式披露**：SKILL.md 精简，细节放 references 按需读取。
